# 🧠 Vitday – Custom Shopify Theme

This is the full exported theme for **Vitday**, a brand focused on vitamin supplements. While the project is based on Shopify’s Sense theme and was developed by a third-party company, I worked and customized several pages and sections to fix and fit the brand's vision and user journey.

---

## 🚀 Highlights of My Work

✅ Custom pages (`nosotros`, `recommendations`, `botes-3x2` )
✅ Custom product recommendation logic with quiz integration (JUST LIKE FITDAY but even more complex)
✅ Custom sections like `carrusel-productos` (uses slick carousel for easy, clean code)
✅ Clean UX improvements, mobile-first design and metafield-driven components  
✅ Integration with Storefront API, GraphQL and VQB App logic

---

This is a full Shopify theme export for review purposes. **Assets which include private API keys, customer data, and store settings have been excluded or anonymized.**
